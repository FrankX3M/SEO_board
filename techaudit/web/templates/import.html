Колонки: site (ключ сети), type (код типа страницы), url (путь или полный адрес), необязательные note и status (active / gone). Понимаются и русские названия (сеть, тип, адрес, комментарий, статус). Если колонки site нет, выберите сеть выше — тогда файл может быть в старом формате type,url,note, как в registry/*.csv. Строки, начинающиеся с #, пропускаются.

Режим «Заменить» удаляет из выбранных сетей все URL, которых нет в файле, — используйте после предпросмотра, он покажет число удаляемых строк. Если в файле есть ошибки, замена ничего не удаляет.
