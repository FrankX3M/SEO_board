Страницы-сироты: индекс против краула

Берём страницы, которые поисковики держат в индексе (Яндекс Вебмастер, Google Search Console), и сверяем с краулом Screaming Frog. Сирота — страница из индекса, до которой краул не добрался: на неё нет ссылок, либо путь от главной слишком длинный (глубже порога «Глубина по краулу» в настройках: сейчас {{ max_depth }}).

1. Выгрузка индексируемых страниц

{% if not has_ywm %}нет токена — «Доступ → Внешние сервисы»{% endif %}
{% if not has_gsc %}нет сервисного аккаунта GSC для сети{% endif %}

Вебмастер: API отдаёт не более 50 000 страниц в поиске; если сайт больше — добавьте выгрузку из интерфейса («Индексирование → Страницы в поиске → Скачать»). Google: у API нет списка проиндексированных страниц, поэтому берутся страницы с показами за выбранный период (нижняя граница). Полный список можно выгрузить из отчёта «Индексирование страниц» и загрузить файлом (Google отдаёт до 1000 строк на выгрузку). В файле нужна колонка URL / Адрес / Страница / Page либо просто список адресов.
