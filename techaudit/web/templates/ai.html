Как применяется ИИ

ИИ — необязательный помощник поверх проверок. Он ничего не решает: статусы «пройдено / не пройдено» считает код по детерминированным правилам.

Что делает

  1. Сводка для руководителя — 3–6 предложений: общее состояние и главные риски для индексации.
  2. Первопричины — группирует проблемы: одна правка, закрывающая сразу несколько пунктов.
  3. Черновики задач для трекера: заголовок, приоритет, описание, примеры URL.
  4. Черновик комментария к каждому проваленному пункту — виден внутри проверки, в отчёте HTML и в колонке «ИИ» файла XLSX.
  5. Для пункта «текстовые описания» — смотрит фрагменты текста страниц и отвечает, есть ли SEO-описание и не скрыто ли оно.

Что уходит в модель и что — нет

  • Уходит: названия и результаты проваленных проверок, до 3 примеров URL с короткой причиной, фрагменты текста страниц (до 500 символов) для проверки описаний.
  • Не уходит: HTML целиком, заголовки ответов, токен сайта, cookie, ключи других сервисов.
  • Текст страниц в запросе помечен как данные, а не инструкции.
  • Ответы кешируются в БД по хешу входных данных: повторный анализ того же результата не тратит запросы.
  • Лимит запросов на запуск — AI_MAX_REQUESTS; без AI_API_KEY этап просто пропускается.
